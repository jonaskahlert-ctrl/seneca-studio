# Modul: Teleprompter-Manuskript erstellen (Schritt 01)

Dieses Modul bereitet schriftliche Artikel oder Notizen so auf, dass sie frei und natürlich vom Kameramonitor abgelesen werden können:

1. **Sprechbare Sätze**: Lange Schachtelsätze werden in klare, mündlich klingende Hauptsätze umgewandelt.
2. **Übersichtliche Blöcke**: Der Text wird in vier bis fünf thematische Abschnitte gegliedert (für etwa 60 bis 75 Sekunden Sendezeit).
3. **Optische Lesehilfen**: Betonte Wörter erhalten den Hinweis `[BETONUNG]`, sinnvolle Atempausen werden mit `[ATEMPAUSE]` markiert.
4. **Erster Satz für den Toncheck**: Der erste Satz wird zugleich ohne Sonderzeichen für die kurze Tonprüfung in Schritt 2B bereitgestellt.
